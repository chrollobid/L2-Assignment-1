# L2 Assignment 1: TypeScript & OOP

The Apollo-Level2-Web-Dev/B8A1 repository is an assignment project from the Programming Hero Level-2 Web Development Course.   


Core Focus & Objective:
The project serves as a comprehensive evaluation of fundamental and advanced TypeScript and Object-Oriented Programming (OOP) concepts. It is designed to test a developer's ability to write clean, strongly-typed logic covering:   

Primitive and Complex Types: Managing optional parameters, default parameters, rest parameters, and readonly tuples.  

Type Guarding & Narrowing: Safely handling union types using typeof, instanceof, and the in operator. 

Interfaces & Generics: Creating robust object contracts and writing reusable, generic utility functions.

Object-Oriented Programming (OOP): Implementing class inheritance along with visibility access modifiers (private, protected).   

Asynchronous TypeScript: Handling asynchronous logic, Promises, and error management.
